Mục tiêu thực hiện

Sử dụng một môi trường phát triển trên đám mây để xây dựng và chạy ứng dụng mà không cần tự cấu hình máy chủ vật lý.

Đánh giá khả năng truy cập từ xa, thông số tài nguyên và cơ chế theo dõi mức sử dụng.

Xuất bản kết quả bằng GitHub Pages và liên hệ các hoạt động đã thực hiện với mô hình NIST.

02

Quy trình triển khai ứng dụng

Khởi tạo môi trường

Tạo repository Public trên GitHub và khởi chạy Codespace từ nhánh main. Terminal được cung cấp thông qua trình duyệt để thao tác trực tiếp với môi trường phát triển.

Chuẩn bị Node.js và Express

Sử dụng npm để khởi tạo dự án, cài đặt Express.js, tạo hai thư mục src và docs nhằm tách biệt mã nguồn ứng dụng và trang kết quả.

Xây dựng API Hello Cloud

Tệp src/app.js khai báo endpoint GET /, sử dụng module os để thu thập thông tin môi trường. Tệp src/server.js đảm nhiệm khởi động ứng dụng tại cổng 3000.

Kiểm tra truy cập qua Internet

API được kiểm tra trên máy tính và điện thoại. Cổng 3000 được chuyển sang Public để thử nghiệm, sau đó chuyển lại Private để hạn chế truy cập.

Tổng hợp và xuất bản kết quả

Thu thập số liệu bằng PowerShell, API và GitHub Billing Usage. Viết trang HTML trong thư mục docs, đồng bộ Git và xuất bản website thông qua GitHub Pages.

03

Kết quả API Hello Cloud

Ứng dụng được xây dựng bằng Express.js và cung cấp endpoint GET /. Khi có yêu cầu HTTP, ứng dụng truy xuất thông tin hệ thống bằng module os của Node.js rồi trả về dữ liệu JSON. 

{
  "message": "Xin chào từ đám mây!",
  "host": "codespaces-6ae62e",
  "platform": "Linux 6.8.0-1064-azure",
  "cpus": 2,
  "memoryGB": 7.8,
  "uptimeSec": 2137,
  "time": "2026-11-05T07:45:21.090Z"
}
Nhận xét kết quả: Các trường host, platform, cpus và memoryGB cho thấy API đã truy xuất được thông tin môi trường chạy ứng dụng. Trường uptimeSec và time thay đổi theo thời điểm truy cập, trong khi tên host có thể thay đổi khi môi trường được cấp phát lại.

Kết quả kiểm tra trên điện thoại xác nhận API có thể được truy cập từ thiết bị khác khi cổng chuyển tiếp được đặt ở chế độ Public. Sau thử nghiệm, cổng đã được chuyển về Private.

04

So sánh máy cá nhân và Codespaces

Bảng so sánh được xây dựng từ thông số thực tế của máy Windows cá nhân, kết quả API Hello Cloud và thông tin GitHub Billing Usage.

Tiêu chí Máy cá nhân GitHub Codespaces
Thời gian chuẩn bị đến khi chạy node -v Node.js v24.20.0 đã được cài đặt. Chưa đo thời gian thiết lập ban đầu. 202,77 giây để Terminal sẵn sàng. Vượt mục tiêu dưới 120 giây của đề.
Số CPU và RAM AMD Ryzen 7 4800H, 8 nhân, 16 luồng; RAM 15,4 GB. API báo cáo 2 CPU logic và RAM 7,8 GB.
Hệ điều hành Windows 11 Home Single Language, 64-bit. Linux, kernel 6.8.0-1064-azure.
Truy cập từ thiết bị khác Nếu chạy dịch vụ trực tiếp trên máy, cần cấu hình mạng, tường lửa hoặc giải pháp triển khai phù hợp. Sử dụng URL chuyển tiếp cổng 3000. Đã thử nghiệm bằng điện thoại khi chuyển cổng sang Public.
Chi phí và cách đo Chi phí mua thiết bị, điện năng, đường truyền Internet; chưa đo thành tiền. Theo Billing Usage tháng 11/2026: 0,37 giờ compute 2-core, 0,49 GB-tháng lưu trữ; hóa đơn $0.
Lưu ý về số liệu: Thời gian 202,77 giây là thời gian đo từ lúc tạo Codespace đến khi Terminal sẵn sàng, chưa phải phép đo riêng thời điểm node -v hoàn tất. Thông số RAM từ API phản ánh giá trị do Node.js báo cáo, không nhất thiết là giới hạn bộ nhớ riêng được cấp cho container.

Nhận xét so sánh

Máy cá nhân cung cấp quyền sử dụng trực tiếp phần cứng và môi trường Windows quen thuộc. Tuy nhiên, khi cần chuyển sang một máy khác, người dùng có thể phải cài lại phần mềm và cấu hình các công cụ phát triển.

GitHub Codespaces cung cấp một môi trường lập trình từ xa được gắn với repository. Người dùng có thể truy cập qua trình duyệt, sử dụng các công cụ đã cấu hình và theo dõi mức tiêu thụ tài nguyên thông qua Billing.

05

Năm đặc tính điện toán đám mây theo NIST

NIST định nghĩa năm đặc tính thiết yếu của điện toán đám mây. Các nội dung sau liên hệ từng đặc tính với thao tác thực tế trong bài Lab 1.

01

On-demand Self-service

Tự phục vụ theo yêu cầu

Người dùng có thể chủ động yêu cầu tài nguyên điện toán mà không cần tương tác thủ công với nhân viên của nhà cung cấp.

Minh chứng: Sinh viên nhấn Create codespace on main và tự khởi tạo môi trường phát triển thông qua giao diện GitHub.

02

Broad Network Access

Truy cập mạng rộng rãi

Các dịch vụ đám mây có thể truy cập qua mạng bằng những cơ chế chuẩn, hỗ trợ nhiều loại thiết bị khác nhau.

Minh chứng: API được truy cập từ máy tính và điện thoại qua URL HTTPS sau khi cổng 3000 được chuyển sang Public.

03

Resource Pooling

Gộp tài nguyên

Nhà cung cấp tổ chức tài nguyên tính toán, lưu trữ và mạng thành các nhóm dùng chung, phân bổ linh hoạt cho nhiều người dùng.

Liên hệ: Codespaces chạy trên cơ sở hạ tầng do GitHub quản lý. Sinh viên sử dụng môi trường ảo mà không phải lựa chọn máy chủ vật lý cụ thể.

04

Rapid Elasticity

Co giãn nhanh

Tài nguyên đám mây có khả năng được cấp phát hoặc thu hồi nhanh theo nhu cầu sử dụng.

Liên hệ: Sinh viên khởi tạo Codespace khi cần thực hành và có thể dừng môi trường sau khi hoàn tất. Bài này chưa kiểm thử tăng hoặc giảm CPU, RAM tự động.

05

Measured Service

Dịch vụ có thể đo lường

Hệ thống đám mây có thể giám sát và ghi nhận việc sử dụng tài nguyên để phục vụ quản lý, báo cáo và tính chi phí.

Minh chứng: GitHub Billing Usage thể hiện 0,37 giờ compute, 0,49 GB-tháng lưu trữ và số tiền được tính vào hóa đơn hiện tại bằng 0 USD.

Kết luận về NIST: Bài thực hành minh họa rõ khả năng tự phục vụ, truy cập qua mạng và đo lường tài nguyên. Hai đặc tính gộp tài nguyên và co giãn nhanh được liên hệ thông qua cách vận hành Codespaces, nhưng chưa được kiểm chứng đầy đủ bằng phép đo chuyên sâu.

07

Đánh giá và kết luận

Kết quả đạt được

Sinh viên đã xây dựng thành công ứng dụng API Hello Cloud bằng Node.js và Express.js trên GitHub Codespaces. API trả về dữ liệu JSON từ môi trường chạy ứng dụng, đồng thời được kiểm tra từ máy tính và điện thoại.

Bài thực hành cũng hoàn thành việc thu thập thông số máy cá nhân, kiểm tra tài nguyên Codespaces, khảo sát Billing Usage và xây dựng website kết quả bằng GitHub Pages.

Ưu điểm và hạn chế

Ưu điểm của môi trường đám mây là khả năng truy cập từ xa, chuẩn bị công cụ tương đối thuận tiện và theo dõi tài nguyên sử dụng. Hạn chế gồm sự phụ thuộc vào kết nối Internet, thời gian khởi tạo và giới hạn tài nguyên theo gói dịch vụ.

Đánh giá mục tiêu thời gian: Lần cấp phát Codespace ghi nhận 3 phút 22,77 giây, vượt mục tiêu dưới 2 phút được nêu trong đề. Đây là kết quả đo thực tế của lần thử nghiệm.
