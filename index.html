4. Năm đặc tính điện toán đám mây theo NIST

1. On-demand Self-service - Tự phục vụ theo yêu cầu

Sinh viên tự khởi tạo GitHub Codespaces thông qua trình duyệt mà không cần yêu cầu quản trị viên cấp phát máy thủ công.

2. Broad Network Access - Truy cập mạng rộng rãi

API được truy cập qua URL trên Internet từ máy tính và điện thoại, minh họa khả năng sử dụng dịch vụ từ nhiều thiết bị.

3. Resource Pooling - Gộp tài nguyên

Codespaces cung cấp môi trường chạy ứng dụng trên hạ tầng do nhà cung cấp quản lý. Sinh viên sử dụng tài nguyên tính toán mà không cần sở hữu máy chủ vật lý riêng.

4. Rapid Elasticity - Co giãn nhanh

Môi trường Codespaces có thể được khởi tạo, dừng và khởi động lại theo nhu cầu. Việc này minh họa khả năng cung cấp và thu hồi tài nguyên nhanh, dù bài thực hành chưa đo việc tăng giảm cấu hình CPU hoặc RAM.

5. Measured Service - Dịch vụ đo lường được

Sinh viên truy cập GitHub Billing Usage để kiểm tra mức sử dụng compute và lưu trữ. Hệ thống ghi nhận 0,37 giờ compute 2-core, 0,49 GB-tháng lưu trữ và chi phí được tính vào hóa đơn là 0 USD.

6. Kết luận

Qua bài thực hành, sinh viên đã sử dụng GitHub Codespaces để triển khai môi trường lập trình Node.js trên đám mây, xây dựng API Hello Cloud bằng Express.js và kiểm tra truy cập từ nhiều thiết bị.

Việc so sánh với máy cá nhân giúp nhận thấy những điểm khác biệt về tài nguyên, cách chuẩn bị môi trường, khả năng truy cập và quản lý chi phí. Đồng thời, các thao tác đã thực hiện giúp liên hệ thực tế với năm đặc tính điện toán đám mây theo NIST.
